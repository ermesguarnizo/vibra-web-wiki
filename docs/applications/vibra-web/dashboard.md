# Vibra Web — Dashboard

Aplicación de dashboard moderno construido con **Next.js** y **TypeScript** para la administración del ecosistema Vibra.

## Estado

En desarrollo activo.

## Módulos

- **Actividades**: Gestión CRUD de actividades educativas
- **Emociones**: Gestión de emociones y estados de ánimo
- **Participantes**: Gestión de participantes y sus relaciones
- **Cursos**: Gestión de cursos e instituciones
- **Feedback**: Recepción y conversión de feedback a ideas
- **Analytics**: Dashboard de gráficas y monitoreo
- **Usuarios**: Gestión de usuarios, roles y permisos
- **Pretests**: Gestión de evaluaciones preliminares
