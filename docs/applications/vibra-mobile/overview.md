# Vibra Mobile

Aplicación móvil del ecosistema Vibra construida con **Expo** y **React Native** para estudiantes y participantes.

## Estado

En desarrollo activo.

## Módulos

- **Actividad Diaria**: Tab de eventos con actividad configurada para el día
- **Retos**: Tab de actividades grupales y desafíos
- **Eventos Personales**: Tab de eventos personales del participante
- **Perfil**: Perfil del participante con progreso, nivel y leaderboard
- **Offline**: Soporte para modo sin conexión

## Tecnologías

- **Framework**: Expo (React Native)
- **Navegación**: expo-router
- **Estado**: React Context + AsyncStorage
- **Animaciones**: React Native Animated / Lottie
